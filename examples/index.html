@barcodesgg/scanner examples

Run npm run build && npm run serve, then open a demo. The demo lookup endpoint (/api/lookup/{barcode}) knows one product: 5012345678900.

  • Web component — default UI, lookup + manual entry
  • Web component, themed — CSS variables, ::part(), slots, messages
  • Headless vanilla — scan-only, your own markup
  • examples/react/ — React hook (Vite app, see its README)
  • examples/proxy-server/ — Express & Laravel lookup proxies
